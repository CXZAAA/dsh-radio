# 设计基线（v0.1）

## 用户任务

在工作区里写代码、跑 agent 的同时，听一个合成波/氛围电台。不需要挑歌、不需要曲目信息，要的是**常驻、随手能开、不打扰**。

## 主动作

打开 dsh → 状态行里看见电台入口 → 点一次 → 出声。之后切台、暂停、调音量都在同一条细条和它的面板里完成。

## 选定方向：B · 静音条

来源：`design/directions/b.html`（看实际画面）。
北冰星：它应该像标签页上的静音图标——安静到几乎不存在，只在需要时被看见。

关键决定：

1. **全页只有一处强调蓝**：播放/下一台符号与台名保持灰度；强调蓝只给 4px 状态点和频谱小方柱，不做发光或渐变。
2. **面板去色块**：28px 行高 + 右对齐来源列建立节奏；当前台只有 2px 灰线 + 台名提亮。面板内加一条横跨内容宽的频谱带，右上角一枚 12px 齿轮。
3. **三态用背景与边框档位递进**：常态 `bg-l1`、hover `bg-l2`、展开 `bg-l3`，不额外加元素。
4. 字体全部跟随 DSH 原生栈，数字用 `tabular-nums`；不提供字体设置。

## 落位

- 唯一位置：`conversation.composer.dock`（`id: 'radio'`，`order: -1`）的第一个胶囊，与 `12 轮 49 步`、`3.4M tok · 缓存命中 98%` 同高并排。
- 不再提供位置设置；`shell.bottom` / `shell.overlay` 的注册与样式已删除。旧 localStorage 里的 `placement` 字段解析时忽略。
- 面板：360px 宽，从胶囊向上弹出，距状态行 6px；用 `fixed` + 锚点跟随（composer 容器是 `overflow:auto`，不能用 absolute）。

## 状态

收起态（未展开）**始终**是完整结构，不折叠成「▶ 电台」：

`[播放/暂停] [下一台] [台名] [频谱]`，高 24px；播放中台名后带 4px 蓝点。

| 状态 | 表现 |
| --- | --- |
| 待机 | 播放图标 + 当前台名（无记录时为 ChillSynth）+ 静止矮柱频谱 |
| 加载 | 暂停图标 + 台名旁三点脉冲（1.2s）+ 频谱低幅呼吸 |
| 播放 | 暂停图标 + 台名 + 蓝点 + 真实数据频谱 |
| 失败 | 红点 + 台名位置显示 `连接失败，点击重试`；播放键与文案都可重试 |
| 展开 | 面板浮层：电台列表 + 频谱带 + 紧凑音量条，当前台高亮 |

频谱：强调色小方柱。收起态 28 根（1.5px 宽、2px 间距、高 3–14px、铺满约 95px）；面板内 56 根，横跨约 328px 内容宽、高 4–20px。透明度和高度都跟随幅度（0.35–1）。

## 动效

- 切台：旧台名 120ms 淡出、新台名 180ms 淡入，宽度用 `--name-w` 预留，不跳动。
- 出声：频谱 180ms 淡入，不弹跳。
- 展开/收起：150ms，向上 4px 位移 + 淡入。

## 设备与验收

- 桌面 Chrome 为主，iPad/Safari 走 Tailscale 为附加验证。
- 明暗主题都要成立；只用 `--dsw-*` token，不硬编码颜色（除失败态的红点）。
- 验收见 `docs/acceptance.md`。
