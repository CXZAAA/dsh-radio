## 已确认事实（非逐条验收，供参考）

- 状态行胶囊可见；播放/暂停与面板可用；面板底部控制行为「左侧播放/暂停 + 下一台，右侧喇叭 + 112px 滑杆 + 百分比」——均为用户口头确认（U）。
- `design/shots/` 现有截图（`dock-idle.png`、`dock-playing.png`、`bar-zoom.png`、`panel-zoom.png`、`panel-list.png`、`panel-settings.png`、`panel-track.png`、`panel-track-zoom.png`）全部是 H 类 harness 截图。
- 单元测试覆盖：电台数据、设置解析、Icecast/RP 解析与缓存、宿主路由（GET/HEAD/405/400/502/10 秒缓存）、播放器状态机、store 切台与曲目拉取、i18n、渲染。

- 2026-10-24：重启后从真实 dsh 直接请求宿主路由，全部符合预期——`GET /plugins/dsh-plugin-radio/now-playing?station=main-mix` → 200 JSON（R.E.M. / All the Right Friends）、`station=mellow-mix` → 200 JSON、未知 station → 400、POST → 405。说明宿主半侧已在真实进程里注册并生效。
