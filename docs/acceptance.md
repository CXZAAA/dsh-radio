# 验收清单（v0.1）

在真实 dsh Web GUI（`http://127.0.0.1:3080`）里逐条验证，记录结果与证据。

1. **入口可见**：打开任意会话，状态行出现 `[播放] [下一台] [台名] [频谱]` 胶囊，与「12 轮 … · tok/s」「… tok · 缓存命中 …%」同高（24px），不挤压聊天区、不换行。
2. **一次点击出声**：点胶囊播放键 → 立即进入「连接中…」态 → 12 秒内出声（大陆 5G 实测基准 1.8–6.7s）。
3. **预缓冲有效**：刷新页面后，点播放的出声时间明显短于冷启动（对照：清 localStorage 后首播）。
4. **七个电台**：逐个切换都能出声；切换过程无叠音、无静音残留。
5. **暂停/恢复**：暂停后再播放，恢复当前台，不重新缓冲整段。
6. **音量与静音**：滑杆与静音按钮生效，刷新后保持。
7. **记忆**：刷新后胶囊仍显示上次的电台（暂停态），点一次即续播；开关关闭时回到默认台。
8. **失败处理**：断网或改错地址时进入失败态（红点 + 重试），重试可恢复；12 秒超时不会永久卡在加载态。
9. **下一台**：点胶囊里的下一台按钮，按列表顺序切换并立即播放；末尾回到第一台，不叠音。设置里不再有「投放位置」。
10. **媒体键**：开关打开时系统媒体面板/键盘媒体键能暂停与恢复；关闭后不再响应。
11. **主题**：明暗两套主题下颜色、对比度正常，无硬编码深色残留。
12. **不干扰**：切换会话、切到轨迹面板、滚动聊天、打开文件预览，播放不中断，dsh 原有 UI 无回归。
13. **控制台**：无报错、无未捕获异常、无 React 警告。
14. **移动端（附加）**：iPad Safari 经 Tailscale 打开，能播放与切台。
